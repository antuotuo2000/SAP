一、先说结论：SAP 是一家什么样的公司？

我的判断：

SAP 是一家值得长期研究的优秀企业，但目前的估值并不便宜。

它与普通软件公司最大的区别在于：SAP 不只是卖软件，而是帮助大型企业管理整个经营体系。

例如，一家大型制造企业可能使用 SAP 管理：

  • 采购：原材料从哪里购买。
  • 库存：仓库里还有多少货物。
  • 生产：生产计划、成本、效率。
  • 财务：收入、成本、利润、现金流。
  • 人力资源：员工工资、组织架构。
  • 供应链：从供应商到客户的整个流程。

SAP 的软件一旦深入企业经营，替换成本就非常高。

这意味着 SAP 不需要每年重新说服客户购买产品，而是可以持续获得企业的订阅、维护和云服务收入。

我认为这是它最重要的投资价值。

二、主营业务：SAP 究竟靠什么赚钱？

SAP 的业务可以分成四大块：

业务主要产品收入来源
ERP企业管理SAP S/4HANA企业订阅、软件授权
云计算SAP Cloud ERP云订阅费用
采购供应链SAP Ariba企业采购平台服务
人力资源SuccessFactors企业人力资源软件订阅

其中最重要的是 ERP 和云业务。

为什么 ERP 如此重要？

假设一家企业已经使用 SAP 运行了10年。

它的财务、库存、采购、生产、供应链数据都在 SAP 系统中。

如果更换系统，就需要：

  • 迁移大量历史数据。
  • 重新设计业务流程。
  • 培训员工。
  • 对接供应商和客户系统。
  • 承担系统迁移失败的风险。

所以企业很难轻易更换 SAP。

这就是典型的高转换成本护城河。

我的理解：SAP 卖的不是一个软件，而是企业经营的基础设施。

  • SAP 最重要的竞争对手之一。
  • 在数据库、ERP、企业云方面竞争。
  • 同样拥有很强的企业客户黏性。

  • Azure、Office、AI 形成生态优势。
  • 在中型企业市场尤其值得关注。

  • 云原生架构是其优势。

我的判断是：

SAP 的核心优势不是技术永远领先，而是企业业务流程已经深度绑定。

这是比单纯技术领先更难被替代的竞争优势。

但要注意，云计算和 AI 可能改变企业软件的竞争格局，不能认为 SAP 的护城河永远不会受到侵蚀。

五、AI 对 SAP 是机会还是威胁？

这是我认为未来3–5年最重要的问题之一。

我认为 AI 对 SAP 有两面性。

机会：

  • AI 可以自动处理企业财务流程。
  • AI 可以优化采购和供应链。
  • AI 可以自动生成经营分析报告。
  • AI 可以降低企业使用复杂 ERP 的门槛。
  • AI 可以提高 SAP 产品的附加价值。

SAP 的优势在于拥有企业内部真实业务数据和流程。

例如，普通 AI 可以分析一家企业的财务数据，但 SAP 能够直接连接采购、库存、生产、销售和财务流程。

这种业务场景是有价值的。

风险：

  • 微软可能利用 Azure 和 Copilot 抢占企业入口。
  • Oracle 可能通过数据库和云基础设施扩大优势。
  • AI Agent 可能改变传统 ERP 的交互方式。
  • AI 可能让企业更容易开发部分替代性软件。

我的判断：

AI 短期更可能增强 SAP 的产品价值，但长期不能排除它改变企业软件的竞争结构。

因此，不能只因为 SAP 有 AI，就给它更高估值。

特别值得肯定的是，SAP 没有固守传统软件授权模式，而是主动推动客户向云 ERP 转型。

不过，云转型也存在代价：传统维护收入可能下降，云基础设施和研发投入可能增加。

公司在2026年财报中也明确预计，未来几年软件支持收入下降速度会加快。

这意味着转型期间的收入结构和利润率需要持续跟踪。

九、SAP 最大的风险是什么？

我认为有六个风险值得长期跟踪。

风险严重程度具体问题
AI 替代风险高AI Agent 可能改变传统 ERP 使用方式

竞争风险高Oracle、微软持续竞争
估值风险高目前估值已经反映较好的增长预期
宏观经济风险中企业削减 IT 预算会影响新订单
汇率风险中欧元收入、美元 ADR，存在汇率影响

特别是 AI 风险，我不认为 SAP 会轻易被淘汰，但也不认为它可以完全不受 AI 冲击。

未来要重点观察：

  • Current Cloud Backlog 是否持续增长。
  • 云业务增长是否开始明显放缓。
  • 自由现金流能否达到管理层目标。
  • 营业利润率能否持续提升。
  • AI 产品是否真正产生额外收入，而不只是增加研发成本。
